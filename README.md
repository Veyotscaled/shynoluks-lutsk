# VINSHYNA / Львів / Демоконцепт

Український демонстраційний сайт шиномонтажу Vinshyna на Стрийській, 61. Статичні HTML, CSS і JavaScript, без залежностей. Для локального перегляду запустіть `node preview.mjs`; перевірка структури — `node check.mjs`.

GitHub Pages: https://veyotscaled.github.io/vinshyna-lviv/
Репозиторій: https://github.com/Veyotscaled/vinshyna-lviv
Вміст локальної теки `dist` публікується в корені гілки `main`. Метадані — `deployment.json`.

Сайт створений як приклад для показу бренду, має позначку «Демоконцепт / Неофіційний сайт».

Послуги: шиномонтаж, балансування, ремонт шин та вулканізація, рихтування, аргонне зварювання, порошкове фарбування дисків. Ціни, строки та гарантії не вигадані. Запис веде до телефону та Instagram.

Дві гарнітури: Unbounded 700 та Onest. Поява першого екрана і секцій, послідовна поява карток, плавні переходи кнопок і модальних вікон. Системне налаштування зменшення руху враховано. Мобільне меню, FAQ і деталі кожної послуги працюють без сторонніх бібліотек.
