# ШиноЛюкс / Луцьк / Демоконцепт

Український демонстраційний сайт для Shynoluks (ШиноЛюкс). Статичні HTML, CSS і JavaScript без залежностей. Локальний перегляд: `node preview.mjs`. Перевірка структури: `node check.mjs`.

GitHub Pages: https://veyotscaled.github.io/shynoluks-lutsk/
Репозиторій: https://github.com/Veyotscaled/shynoluks-lutsk
Вміст локальної теки `dist` публікується в корені гілки `main`. Метадані — `deployment.json`.

Сайт створений як приклад для показу бренду, із позначкою «Демоконцепт / Неофіційний сайт».

## Макет і взаємодія

Дві гарнітури: Unbounded 700 та Onest. Темна тема, червоний акцент, великі похилі заголовки, картки зі зрізаними кутами. Поява секцій і карток при прокручуванні, плавні переходи кнопок, модальних вікон і прайсу. Системне налаштування зменшення руху враховано. Перемикачі цін підтримують клавіатуру.

Оригінальні ілюстративні фотографії створено вбудованим ImageGen. Це матеріали демо, а не фотографії приміщення чи робіт ШиноЛюкс. Логотип у макеті — типографічна інтерпретація для концепту.
